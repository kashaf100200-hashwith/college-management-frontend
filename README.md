# 🎓 College Management Frontend

A simple and beginner-friendly **College Management Frontend** built using **HTML, CSS, and JavaScript**.

This project was created as part of my frontend development learning journey to practice responsive layouts, UI design, CSS animations, transitions, and JavaScript interactivity.

## ✨ Features

- 🎓 College Management Homepage
- 👨‍🎓 Student Information Cards
- 📚 Department Section
- 🎉 Upcoming Events
- 📩 Contact Form
- 💫 Hover Effects & Smooth Transitions
- ✨ Simple CSS Animation
- 📱 Responsive Design
- 🔔 Interactive JavaScript Buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎨 Design

The project uses a **light, soft and modern UI** with pastel colors, simple cards, emojis, images, hover effects, and smooth transitions.
